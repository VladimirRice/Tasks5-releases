# Tasks 5 — сборки

Личный таск-менеджер: задачи и списки, журнал выполнений, напоминания, вложения. Windows и Android.
Работает офлайн; синхронизация между своими устройствами — через **ваш** Яндекс.Диск, данные в облаке
зашифрованы мастер-паролем. Здесь лежат только готовые файлы, исходный код — в закрытом репозитории.

## Скачать

**[Последняя версия](../../releases/latest)** — оттуда нужен один файл:

| | файл | размер |
|---|---|---|
| Windows | `Tasks5-x.y.z.msi` | ~129 МБ |
| Android | `Tasks5-x.y.z.apk` | ~40 МБ |

- **Windows:** запустить `.msi`. Права администратора не нужны, установка в профиль пользователя.
  Windows скажет «Неизвестный издатель», SmartScreen может перехватить запуск: «Подробнее» →
  «Выполнить все равно».
- **Android:** открыть `.apk` и разрешить установку из этого источника (спрашивается один раз).
  Новая версия ставится поверх прежней, данные и настройки остаются.

## Обновления

Дальше эта страница не нужна: обновления ищет само приложение, **Настройки → Обновления**. Оно
проверяет этот канал при запуске (не чаще раза в час), сверяет подпись `version.json` и SHA-256
скачанного файла, а недокачанный или подмененный файл не устанавливает.

## Лицензия

Приложение условно-бесплатное: без ключа работают задачи и локальные функции; облачная
синхронизация, журнал выполнений, автоархивация и голосовые функции открываются ключом или пробным
периодом. Ключ вводится в Настройках → «О приложении» → «Лицензия».
